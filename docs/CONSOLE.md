# 统一设备控制台

入口为 `/index.html`，未登录时进入新的 `/login.html`。账号密码读取设备既有的管理账号库，不创建第二套账号、不修改原密码。登录会话在浏览器标签页中保存，最长 8 小时；退出后管理 API 与 IMS API 均拒绝该会话。

首页和六个功能页共享导航与状态，不加载厂商的 common.js，也不使用 iframe。旧的短信入口、wfc-panel.html 和 wfc-settings.html 跳转到相应新页面。

桌面端采用左侧导航、宽内容区和较大的字号、按钮及开关。短信页在同一屏中显示列表与正文，高度随窗口展开，内容超长时分别滚动；手机端改用列表与阅读视图切换。中文和英文可随时切换。[界面预览](../README.md#界面预览)使用演示数据。

## 服务和网络

独立的管理服务在设备回环地址 17893 运行，由原生 Nginx 代理 `/wfc-admin/`。IMS 服务仍在 17892，通过 `/wfc/` 提供注册状态和发送短信。WFC 关闭或尚未注册时，仍可登录、管理代理与 Wi-Fi、查看短信和编辑转发。

Wi-Fi 使用 Android WifiManager 保存和连接，支持开放网络与 WPA/WPA2 个人网络。连接客户端 Wi-Fi 会关闭同一无线接口上的设备热点；切换网络可能短暂断开页面。开机 Wi-Fi 状态仍由固件负责，安装器不重签厂商 APK。

飞行模式开关只响应用户操作，关闭前提示蜂窝射频将开启并暂停 WFC。读取状态、切换页面、刷新、登录不会修改它。WFC 注册、代理修改和 eSIM 操作均检查当前飞行模式；启动时同时检查 23487 策略。

## eSIM 管理

通过已安装小白卡的标准 ISD-R 管理通道列出现有配置。切换前查验目标确实属于该卡，暂停 WFC，再启用所选配置。切换后确认飞行模式及 SIM 策略；只有 23487 才恢复 WFC，其他配置保留服务关闭状态。

可按用户操作启用、停用和改名，或粘贴 LPA 激活码下载安装；确认码与配置名称可选。删除前显示确认提示，正在启用的配置必须先停用。下载及通知通过当前网络策略访问 SM-DP+；使用“仅代理 Wi-Fi Calling”时，这些 HTTPS 请求走本地网络。

已验证真实小白卡列出四个配置；实际配置切换、下载和删除尚未进行设备验证。普通 SIM、不支持该管理接口的小白卡会显示读取失败，不进行降级写入。不提供恢复出厂或任意 APDU 执行能力。

## 短信和转发

收件箱与已发送读取 Android 原生短信库，最多显示最近 500 条。归档仅保存在本工具的元数据文件中，可以恢复，不删除原始短信。单条删除必须确认，通过 Android 短信提供程序删除并再次查询结果，同时清理对应归档标记；删除后不能通过归档恢复。发送只由用户显式提交，不自动发测试短信。

cURL 编辑器沿用现有配置，Authorization 按用户选择明文显示，其余敏感字段保持掩码。管理服务保存后，运行中的转发服务在入队或投递前重新读取配置；不会把历史收件箱批量加入队列。

## 适配记录

LPA 采用 MIT 项目 [damonto/euicc-go](https://github.com/damonto/euicc-go/commit/8d873a2dfc98f84cc858783e8ca0e4ca04a869bc)，固定代码版本，只适配设备已有的 QMI 传输通道。

该固件的高层 qmi_uim_logical_channel 解析器预期第一个 TLV 是通道号，实际调制解调器先返回 FCI 和状态字，再返回通道号，导致合法响应被误判。独立桥接器按标签解析响应，限制为标准 ISD-R AID 与管理指令，不暴露通用通道。

参考 ABI：[Qualcomm QMI UIM 头文件](https://github.com/bcyj/android_tools_leeco_msm8996/blob/f242858a8cbb2c9ad9b5b2e53d75380ae775727a/qmi/inc/qmi_uim_srvc.h)。厂商二进制仍从设备读取，不包含在开源仓库或安装包中。
