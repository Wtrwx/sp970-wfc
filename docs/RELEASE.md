v0.3.0：全新登录与统一设备控制台。

首页、登录、短信、转发、网络与 eSIM 使用独立前端，不嵌套原生页面。沿用原后台账号，管理服务独立于 WFC 注册运行，退出会撤销共享登录会话。

加入 WFC 与飞行模式开关、Hysteria2 代理设置、原生 Wi-Fi 扫描与连接、现有 eSIM 配置读取与切换入口。短信支持原生收件箱、已发送和可恢复归档；cURL 转发在离线时也可配置，Authorization 显示方式沿用已有选择。

真实设备已验证登录、只读状态、短信读取、Wi-Fi 扫描和 eSIM 配置列表。未测试飞行模式切换、真实 eSIM 切换或断电自启，未发送测试短信。支持边界与安装前提见 README。

附 ARMv7 安装器、源码、第三方许可证与 SHA256SUMS。解压后运行 `python3 setup.py`。
