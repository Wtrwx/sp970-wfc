v0.2.0：短信转发改为直接粘贴 cURL。

首屏只保留转发开关、cURL 命令框和保存按钮。已有配置自动转换为命令，原地址、密钥、成功判定及启用时间保留；Authorization 显示完整值，其他敏感参数继续用星号显示。

支持常用 cURL 请求参数、多行命令、JSON / 表单与短信变量。移除页面中的示例、预览和高级设置。请求解析不会启动 Shell，不读取本地文件，不发送测试短信。

短信转发入口在原生收件箱、SIM 短信和短信设置页保持可见。

附 ARMv7 安装向导、完整源码、第三方许可证和 SHA256SUMS。下载 android-armv7.zip 解压后运行 `python3 setup.py`。

支持已验证的 SP970-B V13 / Android 4.4.4 / root / Magisk / 23487 SIM 环境，其他兼容边界见 README。
